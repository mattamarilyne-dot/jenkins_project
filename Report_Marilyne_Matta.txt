Changes made

I extended the basic Jenkins pipeline with Coverage and
Security Scan stages and implemented a local deployment script.

The Coverage stage runs the unit test using coverage.py,
displays the results, and generates HTML and XML reports.
Jenkins archives these reports before cleaning the workspace.

The Security Scan stage uses Bandit to scan app.py.

The Deploy stage runs deploy.sh, which copies app.py into
/Users/marilynematta/jenkins_deploy/jenkins_project
and runs the deployed copy to verify its output.
